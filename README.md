# MyVoiceInput — vydání

Veřejný kanál s přeloženými verzemi aplikace **MyVoiceInput** —
diktování do libovolného textového pole na macOS. Podržíš pravý Cmd,
mluvíš, pustíš, text se objeví pod kurzorem.

Zdrojový kód je v samostatném privátním repozitáři. Tady jsou jen hotové
balíčky, aby se aplikace mohla sama aktualizovat.

## Stažení

Poslední verze je v [Releases](../../releases/latest). Stáhni `.dmg`,
otevři a přetáhni aplikaci na zástupce Aplikace.

Balíčky jsou podepsané Developer ID a notarizované Applem, takže se
otevřou bez varování. Univerzální binárka, macOS 13 a novější, Intel
i Apple Silicon.

## Co budeš potřebovat

Klíč k ElevenLabs Scribe v `~/.config/elevenlabs/key` (práva `600`).
Bez něj aplikace nahraje zvuk, ale nepřepíše ho.
